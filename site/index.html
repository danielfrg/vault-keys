keys

Secrets from your own HashiCorp Vault, loaded only where they are needed.

Install

macOS or Linux, amd64 or arm64:

curl -fsSL https://danielfrg.github.io/vault-keys/install.sh | bash

Newest build from main:

curl -fsSL https://danielfrg.github.io/vault-keys/install.sh | KEYS_CHANNEL=main bash

Use

export VAULT_ADDR=https://vault.example.com
keys login --user me

# run one command with the secrets, nothing is exported to your shell
keys run ai -- some-command

# or load them into the current shell
eval "$(keys env ai)"
